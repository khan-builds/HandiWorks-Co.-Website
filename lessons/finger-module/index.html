Lesson 1 / Beginner robotics

Build a Finger Module

Move the joints of a model finger, check its travel, and use a virtual button to make it curl and open. You can do all three experiments without a kit.

Enable JavaScript to try the finger simulation. Each rigid link turns around a pivot pin. The pin lets the angle between links change while their lengths stay the same.
