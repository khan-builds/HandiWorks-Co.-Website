The program closes the finger on one press and opens it on the next. Arduino calls a program a **sketch**. Read the note at the end of each line. It says what that line is for.

## The program

```cpp
#include <Wire.h>
#include <Adafruit_MotorShield.h> // The library for the motor shield.

const int buttonPin = 2;    // Button wire. The other button leg goes to GND.
const int motorSpeed = 150; // How hard the motor turns, from 0 to 255.
const int runTime = 1500;   // How long the motor runs for one move, in milliseconds.

Adafruit_MotorShield shield = Adafruit_MotorShield(); // The motor shield on top of the Mega.
Adafruit_DCMotor *finger = shield.getMotor(1);        // The motor on terminal M1.

bool fingerClosed = false;  // false means the finger is open.
bool buttonWasDown = false; // Remembers the last reading so one press counts once.

void setup() {
  pinMode(buttonPin, INPUT_PULLUP); // HIGH at rest, LOW when the button connects the pin to GND.
  shield.begin();                   // Wake up the motor shield.
  finger->setSpeed(motorSpeed);     // Set how hard the motor turns.
}

void loop() {
  bool buttonDown = digitalRead(buttonPin) == LOW; // A press reads LOW because of INPUT_PULLUP.

  if (buttonDown && !buttonWasDown) { // The button just went down.
    fingerClosed = !fingerClosed;      // Flip between open and closed.
    if (fingerClosed) {
      finger->run(FORWARD);            // Turn one way to close the finger.
    } else {
      finger->run(BACKWARD);           // Turn the other way to open it.
    }
    delay(runTime);                    // Let the motor run for the whole move.
    finger->run(RELEASE);              // Stop the motor.
  }

  buttonWasDown = buttonDown; // Save this reading for the next loop.
  delay(20);                   // Wait a little so one press is not counted many times.
}
```

A DC motor does not know where it is. It only turns while it has power. So the program runs it for a set time, `runTime`, and then stops it.

## Upload it

1. Open the Arduino IDE.
2. Go to **Tools, Manage Libraries** and install **Adafruit Motor Shield V2 Library**.
3. Go to **Tools, Board** and choose **Arduino Mega or Mega 2560**.
4. Go to **Tools, Port** and choose the port that appears when the Mega is plugged in.
5. Paste the program, or open `lesson-1-finger.ino` from the download.
6. Click Upload. Wait until it says "Done uploading."

Press the button once. The motor should run, close the finger, and stop. Press it again. The motor should run the other way and open it.

<Callout type="tip" title="Change the movement">
`runTime` and `motorSpeed` are the only numbers you need at first. Change one number, upload again, and watch what the finger does. If the finger does not close all the way, make `runTime` bigger. If the motor hums at the end of the move, it is pushing against a stop: make `runTime` smaller.
</Callout>

## Test it

The build is done when all of these are true.

- Your CAD model shows the base, the drive bar, the joints, and the tip.
- The motor, battery, and button wires match the table.
- The Mega board is set to **Arduino Mega or Mega 2560**.
- One press closes the finger, and the next press opens it.
- Holding the button does not make the finger flap.

<Callout type="tip">
If the finger moves without a press, the button pin is probably not using `INPUT_PULLUP`. If it never moves, check that the battery is connected and that you chose the Mega board before uploading. If it opens when it should close, swap the motor's two wires.
</Callout>

<TeacherOnly title="Common mistakes">
The usual code miss is forgetting `INPUT_PULLUP`, so the pin floats and the motor runs by itself. The usual IDE misses are leaving the board on Uno and not installing the shield's library, so the upload fails. Students also connect the battery before the wiring is checked. The motor has no stop of its own: a `runTime` that is too long leaves it pushing against the end of its travel.
</TeacherOnly>
<TeacherOnly title="Answer key">
1. The drive bar.
2. A round hole with a pin that a link swings on.
3. M1.
4. Pin 2.
5. So the pin reads HIGH until the button connects it to ground.
6. `runTime`: the motor moves the finger for as long as it runs.
7. Unplug the battery and the USB cable.
