This lesson has three parts. First you draw the finger. Then you wire it. Then you program it.

The finished finger is about 11 inches long (288 mm). The example files are saved in **inches**. If your CAD tool asks for units, choose inches. If you choose millimeters, the finger will look tiny.

<Callout type="note" title="New words">
A **joint** is a round hole with a pin through it. A **link** is a bar that swings on a joint. The **servo** is the motor that moves the links.
</Callout>

## Part 1: Draw the finger

You will build the finger in five steps. Each step adds the next piece of the real finger. Do one step at a time.

For every step:

1. Open the example and drag it to turn it around.
2. In your own CAD file, add only the new piece.
3. Put your model next to the example. The shapes should match before you continue.

<Callout type="tip" title="In Tinkercad">
Start a new 3D design. Use boxes for bars and cylinders for round holes. Import the example STL when you want to check your work. Set the import unit to inches.
</Callout>

### Step 1 — The base

The base is the end the finger mounts on. You can see round holes and flat plates. Nothing sticks out to the right yet.

<StlViewer client:visible src="/models/lesson-1/01-base.stl" title="Figure 1. The base" />

In your CAD file, make the mounting plates and the round holes. Leave the rest of the screen empty.

### Step 2 — The drive bar

Add the long bar that comes out of the base. This is the part the servo will push and pull. The finger cannot curl without it.

<StlViewer client:visible src="/models/lesson-1/02-drive.stl" title="Figure 2. The drive bar" />

Keep the base from step 1. Add the long bar onto it. Do not add the finger links yet.

### Step 3 — The first joints

Add the first round joints above the drive bar. Each circle is a hole a pin will pass through. A link will swing on that pin.

<StlViewer client:visible src="/models/lesson-1/03-first-joints.stl" title="Figure 3. The first joints" />

Add those holes to your model. A joint that is too tight will not turn. A joint that is too loose will wobble. Match the example.

### Step 4 — The links

Add the rest of the folding links. They are the bars that reach toward the fingertip. Each new link needs its own joint.

<StlViewer client:visible src="/models/lesson-1/04-links.stl" title="Figure 4. The links" />

Count the round holes in the example, then count the holes in your model. The numbers should match.

### Step 5 — The fingertip

Add the tip. This file is the whole finger. Your model should look like this one when you are done.

<StlViewer client:visible src="/models/lesson-1/05-finished-finger.stl" title="Figure 5. The finished finger" />

Turn both models all the way around. Check the base, the drive bar, every joint, and the tip.

<Callout type="tip">
If a piece looks wrong, go back one step and fix that piece only. Do not start the whole finger over.
</Callout>

## Part 2: Wire the Arduino Mega

The Mega is the board that will tell the servo how far to turn. Unplug the USB cable before you move any wire.

<Callout type="safety">
A moving link can pinch. Keep your fingers off the joints while the servo is powered. If a part feels hot or the finger stops halfway, unplug the USB cable first.
</Callout>

Use these connections. The servo has three wires. The button has two legs.

| Wire | Connect it to |
| --- | --- |
| Servo ground (brown or black) | Mega GND |
| Servo power (red) | Mega 5V |
| Servo signal (orange or yellow) | Mega pin 9 |
| One button leg | Mega pin 2 |
| Other button leg | Mega GND |

Pin 9 sends the angle. Pin 2 listens to the button. GND is the shared ground. The button does not need a resistor, because the sketch turns on the Mega's built-in pull-up.

One small servo can run from the Mega's 5V pin. If the Mega restarts when the servo moves, the servo needs its own 5V supply. Connect that supply's ground to a Mega GND pin too.

Plug in the USB cable only after every wire is in the right hole.

## Part 3: Program the finger

The sketch closes the finger on one press and opens it on the next. Read the note at the end of each line. It says what that line is for.

```cpp
#include <Servo.h> // The Servo library moves a positional servo to an angle.

const int buttonPin = 2;      // Button wire. The other button leg goes to GND.
const int servoPin = 9;       // Servo signal wire. It is usually orange or yellow.
const int openAngle = 30;     // How far the finger opens. Make this bigger to open more.
const int closedAngle = 120;  // How far the finger closes. Lower it if the servo strains.

Servo finger; // The servo that moves the finger.

bool fingerClosed = false;  // false means the finger is open.
bool buttonWasDown = false; // Remembers the last reading so one press counts once.

void setup() {
  finger.attach(servoPin);          // Pin 9 talks to the servo.
  pinMode(buttonPin, INPUT_PULLUP); // HIGH at rest, LOW when the button connects the pin to GND.
  finger.write(openAngle);          // Start with the finger open.
}

void loop() {
  bool buttonDown = digitalRead(buttonPin) == LOW; // A press reads LOW because of INPUT_PULLUP.

  if (buttonDown && !buttonWasDown) { // The button just went down.
    fingerClosed = !fingerClosed;      // Flip between open and closed.
    if (fingerClosed) {
      finger.write(closedAngle);       // Move to the closed angle.
    } else {
      finger.write(openAngle);         // Move back to the open angle.
    }
  }

  buttonWasDown = buttonDown; // Save this reading for the next loop.
  delay(20);                   // Wait a little so one press is not counted many times.
}
```

Upload it like this:

1. Open the Arduino IDE.
2. Go to **Tools → Board** and choose **Arduino Mega or Mega 2560**.
3. Go to **Tools → Port** and choose the port that appears when the Mega is plugged in.
4. Paste the sketch, or open `lesson-1-finger.ino` from the downloads.
5. Click Upload. Wait until it says "Done uploading."

Press the button once. The servo should move to the closed angle and stay there. Press it again. The servo should move back.

<Callout type="tip" title="Change the movement">
`openAngle` and `closedAngle` are the only numbers you need at first. Change one number, upload again, and watch what the finger does. Stay away from an angle that makes the servo buzz. Buzzing means it is pushing against a stop.
</Callout>

## Test it

The build is done when all of these are true.

- Your CAD model shows the base, the drive bar, the joints, and the tip.
- The servo ground, power, and signal wires match the table.
- The Mega board is set to **Arduino Mega or Mega 2560**.
- One press closes the finger, and the next press opens it.
- Holding the button does not make the finger flap.

<Callout type="tip">
If the finger jitters without a press, the button pin is probably not using `INPUT_PULLUP`. If it never moves, check that the signal wire is in pin 9 and that you chose the Mega board before uploading.
</Callout>

<TeacherOnly title="What the model is">
The five STL files are slices of `Finger 1.stl`, cut along the finger from the base to the tip. Units are inches (the 15 mm features export as 0.59055 in). Students who import as millimeters will see an 11 mm finger. The long bar in step 2 is the drive. The circles after that are the pivot joints. Do not describe a rack and pinion unless you have confirmed that on the hardware.
</TeacherOnly>

<TeacherOnly title="Common mistakes">
The usual code miss is forgetting `INPUT_PULLUP`, so the pin floats and the servo chatters. The usual IDE miss is leaving the board on Uno, so the upload fails or the pins do not match. Students also power the servo before the wiring is checked.
</TeacherOnly>

<TeacherOnly title="Answer key">
1. The drive bar.
2. A round hole with a pin that a link swings on.
3. Pin 9.
4. Pin 2.
5. So the pin reads HIGH until the button connects it to ground.
6. Unplug the USB cable.
</TeacherOnly>

<TeacherOnly title="If the servo resets the Mega">
USB 5V is enough for one unloaded micro servo. A finger that binds will brown out the Mega. Have the student lower `closedAngle` first. If it still resets, move servo power to a separate 5V supply and tie the grounds together. Do not power the servo from a Mega pin other than 5V.
</TeacherOnly>
