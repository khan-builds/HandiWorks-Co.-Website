## How a finger moves

A human finger bends at three joints. This module copies that curl with two coupled four-bar linkages driven by one motor. The motor turns a pinion, the pinion drives a rack, and the rack pulls the linkages so the finger closes in one motion.

![A human finger beside the module's two coupled four-bar linkages](/images/lesson-1-linkage.svg)

<Callout type="note" title="Why one motor">
Both linkages share the same rack, so one motor curls the whole finger. You do not need a servo at every joint.
</Callout>

## Safety first

<Callout type="safety">
Unplug the battery before you adjust any part of the finger. Keep fingers clear of the pinch points where the linkages cross, and let hot glue cool before you touch it.
</Callout>

The motor can stall and heat up if the finger binds. If it stops moving, unplug power first, then find the tight joint.

## Assemble the finger

Work on a clear table. Do not apply power until step 9.

1. Lay out the phalanges, gear housing, rack, pinion, pins, screws, and nuts. Match each part to the viewers above.
2. Press the pinion onto the motor shaft until it sits flush. It should not wobble.
3. Seat the motor in the gear housing and fasten it with the screws from kit bag A.
4. Slide the rack into the housing so its teeth meet the pinion. Move it by hand. It should travel without skipping.
5. Pin the proximal phalanx to the housing. The pin should turn freely. Do not overtighten.
6. Connect the intermediate link between the rack and the proximal phalanx.
7. Pin the intermediate phalanx to the proximal phalanx.
8. Connect the distal link, then pin the distal phalanx in place.
9. Check free movement by hand before powering. The finger should curl and open with light finger pressure and no grinding.
10. Only then connect the battery or USB power.

![The finger parts laid out in assembly order](/images/lesson-1-assembly.svg)

<Callout type="tip">
If a joint feels gritty, loosen that pin a quarter turn and try again. Forcing it will oval the printed hole.
</Callout>

## Wire it up

The button uses pin 2. One leg of the button goes to pin 2, the other leg goes to GND. The motor driver input goes to pin 9, and the motor power leads follow the driver board's labels.

## Program it

The sketch closes the finger on one press and opens it on the next. Read the comments with the code. Each line says what that line is for.

```cpp
// finger-toggle.ino
// One button press closes the finger. The next press opens it.

const int buttonPin = 2; // Button leg. The other leg goes to GND.
const int motorPin = 9;  // Motor driver input. HIGH closes the finger.

bool fingerClosed = false;  // false means the finger is open
bool buttonWasDown = false; // remembers the last reading so we toggle once per press

void setup() {
  pinMode(buttonPin, INPUT_PULLUP); // HIGH at rest, LOW when the button connects the pin to ground
  pinMode(motorPin, OUTPUT);        // this pin drives the motor
  digitalWrite(motorPin, LOW);      // start with the finger open
}

void loop() {
  bool buttonDown = digitalRead(buttonPin) == LOW; // pressed reads LOW because of INPUT_PULLUP

  if (buttonDown && !buttonWasDown) { // the button just went down
    fingerClosed = !fingerClosed;      // flip between open and closed
    digitalWrite(motorPin, fingerClosed ? HIGH : LOW); // HIGH closes, LOW opens
  }

  buttonWasDown = buttonDown; // store this reading for the next loop
  delay(20);                   // wait so a bouncing contact counts as one press
}
```

Upload it from the Arduino IDE with the board and port your teacher names. Then press the button once. The finger should close and stay closed until you press again.

## Test your finger

Run this checklist before you call the build done.

- The finger opens fully and closes fully.
- No joint binds or skips a tooth.
- It completes 10 cycles in a row without stalling.
- The button toggles once per press, not continuously while held.

<Callout type="tip">
If the finger sticks, unplug power, then move it by hand to find the tight joint. Loosen that pin before you power it again.
</Callout>

## Teacher notes

<TeacherOnly title="Timing guide">
- Parts tour: 10 min
- Assembly: 40 min
- Wiring and code: 30 min
- Testing and quiz: 10 min
</TeacherOnly>

<TeacherOnly title="Common mistakes">
The usual miss is forgetting INPUT_PULLUP, so the button floats and the motor chatters. Students also power the finger before the hand-check in step 9.
</TeacherOnly>

<TeacherOnly title="Quiz answer key">
1. It turns the motor's rotation into finger curling.
2. Pin 2.
3. So the pin reads HIGH until the button connects it to ground.
4. Unplug the power.
5. 10 cycles.
</TeacherOnly>

<TeacherOnly title="Assessment and differentiation">
Award full credit when the finger completes 10 cycles without binding. Students who finish early change the sketch so the finger stops halfway.
</TeacherOnly>
